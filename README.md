# classification-mnist
L'objectif est de construire un CNN capable de reconnaître les chiffres manuscrits de 0 à 9 à partir d'images en niveaux de gris de 28×28 pixels. La base de données MNIST est devenue la référence pour tester de nouvelles architectures. Un modèle simple atteint facilement 99 % de précision en quelques minutes d'entraînement
